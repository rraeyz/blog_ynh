Yönetici şifresini belirlemek için https://__DOMAIN__/admin/giris adresini açın ve şu kurulum anahtarını girin:

`__SETUP_TOKEN__`

Anahtarı bilmeyen biri şifre belirleyemez. Kaybederseniz sunucuda `sudo yunohost app setting __APP__ setup_token` ile görebilirsiniz.

Ardından Ayarlar'da yapay zekâ API anahtarını ve Künye bağlantısını (Künye → Ayarlar → Güvenlik → API anahtarı) doldurun.

Set the admin password at https://__DOMAIN__/admin/giris with the setup token above.
